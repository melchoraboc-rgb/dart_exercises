## Scenario Description
This Dart console application calculates a customer receipt for a store purchase. It computes the total price, handles item packaging breakdown using integer division and modulo operators, and evaluates conditional flags for large orders and discount eligibility.

## How to Run
To run this project, ensure you have the Dart SDK installed, then execute the following command in your project terminal:

```bash
dart run
